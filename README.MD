## Project Overview
This project involves analyzing data collected from Reddit. The main notebook for this project is `Reddit_Analysis.ipynb`, and all the collected data is stored in the `data` directory. The required environment variables and dependencies are listed in the `nlp_req.yml` file for setting up a Conda environment.

## How to Run
1. Set up the Conda environment using the `nlp_req.yml` file:
    ```bash
    conda env create -f nlp_req.yml
    conda activate <environment_name>
    ```
2. Run the `Reddit_Analysis.ipynb` notebook to generate the results.
